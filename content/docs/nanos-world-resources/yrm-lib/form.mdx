# YRM.OpenForm

`YRM.OpenForm` permet d'afficher des formulaires interactifs dans l'interface du joueur. Ce module permet de collecter des informations à travers différents types de champs, de définir des valeurs par défaut et de récupérer les données saisies grâce à un callback.

## Utilisation

La fonction `YRM.OpenForm` accepte une table de configuration Lua en premier argument et un callback en second argument pour récupérer les valeurs du formulaire ou son annulation.

### Syntaxe

```lua
YRM.OpenForm({
    title = "Titre du formulaire",
    fields = {
        {
            name = "username",
            label = "Nom d'utilisateur",
            type = "text",
            required = true,
            placeholder = "Saisir un nom..."
        }
    }
}, function(result)

    if result.cancelled then return end

    local values = result.values
    print("Nom d'utilisateur :", values.username)

end)
```

## Paramètres

| Paramètre | Type | Description |
|---|---|---|
| `title` | `string` | Titre affiché dans le formulaire. |
| `fields` | `table` | Liste des champs à afficher dans le formulaire. |
| `callback` | `function` | Fonction appelée pour récupérer le résultat du formulaire. |

## Paramètres des champs

Chaque entrée de `fields` représente un champ du formulaire.

| Paramètre | Type | Description |
|---|---|---|
| `name` | `string` | Identifiant du champ utilisé pour récupérer sa valeur dans `result.values`. |
| `label` | `string` | Texte affiché pour identifier le champ. |
| `type` | `string` | Type de champ à afficher. |
| `required` | `boolean` | Indique si le champ est obligatoire. |
| `placeholder` | `string` | Texte indicatif affiché lorsque le champ est vide. |
| `default` | `any` | Valeur initiale du champ. |
| `disabled` | `boolean` | Indique si le champ est désactivé. |
| `options` | `table` | Liste des options disponibles pour certains types de champs. |
| `min` | `number` | Valeur minimale, notamment pour les champs numériques et les curseurs. |
| `max` | `number` | Valeur maximale, notamment pour les champs numériques, les curseurs et les notes. |

## Types de champs disponibles

| Type | Description |
|---|---|
| `text` | Saisie de texte. |
| `password` | Saisie d'un mot de passe. |
| `number` | Saisie d'une valeur numérique. |
| `search` | Champ de recherche. |
| `url` | Saisie d'une adresse web. |
| `date` | Sélection d'une date. |
| `time` | Sélection d'une heure. |
| `color` | Sélection d'une couleur. |
| `range` | Sélection d'une valeur à l'aide d'un curseur. |
| `toggle` | Activation ou désactivation d'une option. |
| `checkbox` | Case à cocher. |
| `select` | Sélection d'une option dans une liste. |
| `rating` | Attribution d'une note. |

## Options des champs de sélection

Le type `select` utilise le paramètre `options` pour définir les choix disponibles.

Chaque option contient un `label` et une `value`.

| Paramètre | Type | Description |
|---|---|---|
| `options` | `table` | Liste des options disponibles. |
| `options[].label` | `string` | Texte affiché pour l'option. |
| `options[].value` | `any` | Valeur associée à l'option. |

### Exemple

```lua
{
    name = "rank",
    label = "Grade",
    type = "select",
    options = {
        { label = "Recrue", value = "recruit" },
        { label = "Membre", value = "member" },
        { label = "Chef", value = "leader" }
    },
    default = "member"
}
```

## Gestion du résultat

Le callback reçoit une table `result` contenant l'état du formulaire et les valeurs saisies.

| Propriété | Type | Description |
|---|---|---|
| `result.cancelled` | `boolean` | Indique si le formulaire a été annulé. |
| `result.values` | `table` | Contient les valeurs des champs du formulaire. |
| `result.values[name]` | `any` | Valeur associée au nom du champ. |

## Exemple simple

```lua
YRM.OpenForm({
    title = "Profil du joueur",
    fields = {
        {
            name = "username",
            label = "Nom d'utilisateur",
            type = "text",
            required = true,
            placeholder = "Saisir un nom..."
        },
        {
            name = "age",
            label = "Âge",
            type = "number",
            required = true
        }
    }
}, function(result)

    if result.cancelled then return end

    local values = result.values

    print("Nom :", values.username)
    print("Âge :", values.age)

end)
```

## Exemples d'utilisation

### Configuration des préférences

```lua
YRM.OpenForm({
    title = "Préférences",
    fields = {
        {
            name = "color",
            label = "Couleur préférée",
            type = "color",
            default = "#552583"
        },
        {
            name = "notifications",
            label = "Activer les notifications",
            type = "toggle",
            default = true
        },
        {
            name = "accepted",
            label = "J'accepte les conditions",
            type = "checkbox",
            required = true
        }
    }
}, function(result)

    if result.cancelled then return end

    local values = result.values

    print("Couleur :", values.color)
    print("Notifications :", values.notifications)
    print("Conditions acceptées :", values.accepted)

end)
```

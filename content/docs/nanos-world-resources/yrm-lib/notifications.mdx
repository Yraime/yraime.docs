# YRM.Notify

`YRM.Notify` permet d'afficher des notifications visuelles dans l'interface du joueur afin de communiquer une information, confirmer une action ou signaler un avertissement.

## Utilisation

La fonction accepte une table de configuration Lua.

### Syntaxe

```lua
YRM.Notify({
    title = "Titre",
    description = "Description",
    position = "top-left",
    type = "success",
    duration = 5000
})
```

## Paramètres

| Paramètre | Type | Description |
|---|---|---|
| `title` | `string` | Titre de la notification. |
| `description` | `string` | Texte descriptif de la notification. |
| `position` | `string` | Position de la notification à l'écran. |
| `type` | `string` | Type visuel de la notification. |
| `duration` | `number` | Durée d'affichage en millisecondes. |

## Positions disponibles

L'exemple utilise la position `top-left`, qui place la notification en haut à gauche de l'écran.

```lua
position = "top-left"
```

## Types de notification

| Type | Utilisation |
|---|---|
| `accent` | Mettre une information en évidence. |
| `success` | Confirmer la réussite d'une action. |
| `error` | Signaler une erreur. |
| `warning` | Afficher un avertissement. |

## Exemple simple

```lua
YRM.Notify({
    title = "Bienvenue",
    description = "La bibliothèque fonctionne correctement.",
    position = "top-left",
    type = "success",
    duration = 5000
})
```

## Exemples d'utilisation

### Notification de réussite

```lua
YRM.Notify({
    title = "Succès",
    description = "Votre action a été effectuée.",
    position = "top-left",
    type = "success",
    duration = 5000
})
```

### Notification d'avertissement

```lua
YRM.Notify({
    title = "Attention",
    description = "Vous devez vérifier cette information.",
    position = "top-left",
    type = "warning",
    duration = 5000
})
```

### Notification d'erreur

```lua
YRM.Notify({
    title = "Erreur",
    description = "Une erreur est survenue.",
    position = "top-left",
    type = "error",
    duration = 5000
})
```

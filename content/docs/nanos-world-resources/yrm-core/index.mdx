# YRM Core

**YRM Core** est un framework développé en Lua pour [Nanos World](https://nanos-world.com/).

Il centralise plusieurs fonctionnalités essentielles au développement de vos packages, notamment la gestion des bases de données SQL et un système de commandes personnalisables.

<Callout type="info" title="Version 0.1.0">
  YRM Core est actuellement disponible en version **0.1.0**.
</Callout>

## Fonctionnalités

- **SQLite & MySQL** : gestion des bases de données SQL.
- **SQLite automatique** : création de la base de données si elle n'existe pas.
- **Commandes personnalisées** : création et gestion de commandes serveur.
- **Préfixe configurable** : personnalisation du préfixe des commandes.

## Dépendances

YRM Core constitue la base de l'écosystème YRM et est nécessaire au fonctionnement de `yrm-lib`.

Assurez-vous de l'installer et de le configurer avant d'utiliser les bibliothèques qui en dépendent.

## Installation

Retrouvez YRM Core sur le [Nanos World Store](https://nanos-world.com/store/packages/yrm-core).

Pour configurer le framework, consultez la page [Configuration](/docs/yrm-core/configuration).

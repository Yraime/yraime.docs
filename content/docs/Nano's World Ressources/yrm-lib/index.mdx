# YRM Lib (`yrm-lib`)

<Callout type="warn" title="Statut : En cours de développement">
  Cette bibliothèque est actuellement en phase de développement actif. Ne pas utiliser sur un serveur de production principal sans tests préalables.
</Callout>

**YRM Lib** est une bibliothèque UI et utilitaire sur-mesure conçue pour **Nanos World**. Elle repose sur une architecture hybride et fluide combinant du **Lua** (côté client/serveur) et une interface **WebUI** (HTML, CSS, JavaScript).

Elle permet de créer rapidement des interfaces utilisateur modernes et réactives sans avoir à redévelopper chaque composant à partir de zéro.

---

## 🛠️ Téléchargement & Localisation

La ressource est hébergée sur les dépôts officiels du projet. Vous pouvez la récupérer directement depuis notre GitHub ou via le Workshop / Package Manager Nanos World.

* **Dépôt GitHub :** `https://github.com/votre-compte/yrm-lib` *(Privé / Accès développeurs)*
* **Dossier du serveur :** `Packages/yrm-lib/`
